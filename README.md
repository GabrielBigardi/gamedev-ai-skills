# Game Dev AI Skills

This repository contains custom, modular AI skills formatted for immediate use across LLM interfaces (such as Claude Projects, Cursor, Custom GPTs, or local models). Each skill is built around established ludology principles, mechanical rigor, and production-tested workflows.
